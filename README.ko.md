# Klecks 한국어 포크 안내

이 저장소는 오픈소스 그림 앱 **Klecks**를 기반으로, 태블릿/S Pen 작업과 빠른 보조 기능을 실험하기 위한 포크입니다.

원본 Klecks의 MIT 라이선스와 저작권 표시는 그대로 유지합니다. 원본 프로젝트 설명과 전체 기능 목록은 [`README.md`](README.md)를 참고하세요.

## 현재 이 포크에서 추가한 것

### 1. 첫 실행 기본 언어: 한국어

- 기존 Klecks의 한국어 번역을 그대로 활용합니다.
- 이 포크를 처음 실행하면 한국어를 기본 언어로 사용합니다.
- 설정에서 다른 언어를 선택하면 이후에는 사용자가 선택한 언어를 기억합니다.

### 2. S Pen/스타일러스 입력 기반

원본 Klecks에는 이미 Pointer Events 기반의 펜 입력, 필압, 손떨림 보정(stabilizer), 펜 호버 커서가 있습니다.

이 포크에서는 스마트 스트로크 후처리를 위해 다음 정보를 래스터 그림과 별도로 기록할 수 있는 기반을 추가했습니다.

- 캔버스 좌표 `x`, `y`
- 필압
- 입력 시각
- coalesced sample 여부
- pointer id
- 입력 종류(`pen`, `touch`, `mouse`)

브라우저/기기에서 제공하는 스타일러스 기울기·회전·접촉 크기 같은 메타데이터도 내부 Pointer Event 타입에서 보존할 수 있도록 확장하기 시작했습니다.

### 3. 스마트 스트로크 후처리 기반

그림은 계속 **래스터 레이어**에 그립니다. 대신 최근 브러시 스트로크의 벡터 샘플을 작은 메모리 sidecar로 보관합니다.

현재 분석기는 방금 그은 스트로크에 대해 다음 후보를 계산할 수 있습니다.

- `trim`: 기존 선을 짧게 지나쳐 끝부분이 튀어나온 경우
- `connect`: 기존 선의 끝점 근처에서 살짝 덜 그어져 틈이 남은 경우

중요: 현재 단계에서는 분석 결과만 만들며 그림을 자동으로 자르거나 연결하지 않습니다. 오검출이 실제 그림을 망가뜨리지 않게 하기 위한 의도적인 1단계입니다.

다음 단계에서는 방금 그은 스트로크만 안전하게 다시 그릴 수 있는 임시 stroke buffer/undo 경계를 연결한 뒤, 신뢰도가 높은 경우에만 보정을 적용할 예정입니다.

## 로컬 실행

Node.js와 npm이 설치되어 있어야 합니다.

```bash
npm ci
npm run icon:build
npm run lang:build
npm run start
```

개발 서버 없이 정적 결과물을 만들려면:

```bash
npm run build
```

빌드 결과는 `/dist/`에 생성됩니다.

## 이 포크에서 앞으로 실험할 기능

아래 항목은 **아직 구현 완료가 아닙니다.**

- 스마트 스트로크 자동 적용
  - 머리카락 끝의 짧은 X자 overshoot 정리
  - 작은 endpoint gap 자동 연결
  - 끝부분의 국소적인 흔들림 정리
- 선화 기반 채색 정리
  - 선 밖으로 삐져나온 채색 제거
  - 두꺼운 선 아래에 덜 채워진 가장자리 보충
- 주변 채색을 참고한 선화 색 자동 조정
- 가상 그물망/축 + 광원 기반의 보조 명암 생성
- S Pen 버튼 동작을 그림 작업에 맞게 별도 설정하는 기능

이 기능들은 가능한 한 서버 없이 로컬에서 빠르게 동작하는 것을 기본 방향으로 합니다.
