# Alpha-aware 스마트 채색 보정

## 목적

기존 스마트 채색 보정은 안쪽의 빈 픽셀을 복구할 때 alpha를 거의 255로 채워 경계가 지나치게 단단해질 수 있었다. 이 변경은 채색 레이어 자체의 투명도와 선화의 anti-alias / 레이어 opacity를 보정 결과에 반영한다.

## 동작

### 기존 채색 alpha 보존

안쪽 연결 영역에서 이미 칠해진 픽셀들의 평균 alpha를 대표 alpha로 사용한다.

- 주변 채색이 불투명하면 깊은 안쪽은 불투명하게 복구한다.
- 주변 채색이 반투명이면 복구 픽셀도 같은 수준의 alpha를 목표로 한다.
- 무조건 alpha 255로 강제하지 않는다.

### 선화 alpha 보존

선화 분석 mask는 더 이상 0/1만 저장하지 않는다. 합성된 선화의 실제 0~255 alpha를 보존한다.

따라서 얇은 anti-alias 픽셀, 반투명 선, 레이어 opacity가 낮은 선은 경계 보정 강도도 그에 비례해 약해진다.

### 경계 거리 기반 부드러움

판정 원 내부에서 가장 가까운 선화까지의 간단한 거리장을 계산한다.

- 선에서 충분히 먼 안쪽: 해당 영역의 대표 alpha까지 채운다.
- 선에 가까운 안쪽: 선화 alpha와 거리에 비례해 목표 alpha를 낮춘다.
- 선 바로 바깥: 채색을 즉시 0으로 자르지 않고 선화 coverage만큼 일부 남긴다.
- 더 멀리 바깥으로 갈수록 alpha가 0으로 내려간다.

현재 부드러움 폭은 적용 브러시 크기에 따라 자동으로 약 1.5~6px 범위에서 정한다. 실기기 테스트 후 필요하면 별도 UI slider로 노출한다.

## 스트로크 보정 실험 상태

스마트 스트로크 trim/connect 코드는 당장 삭제하지 않고 보존하지만 현재 작업 흐름에서는 비활성화한다.

- Pen 설정 UI에서 보정 항목을 숨긴다.
- 과거 localStorage에 보정 강도가 저장되어 있어도 런타임에서는 `off`로 취급한다.

이유는 스마트 스트로크 보정의 주된 목적이 페인트통/채색 경계 문제를 우회하는 것이었고, 스마트 채색 보정 + 향후 AI virtual barrier가 그 문제를 직접 해결할 가능성이 높기 때문이다.

AI가 끊긴 선을 안정적으로 가상 연결할 수 있게 되면, 사용자는 실제 선화를 자동 수정하지 않고도 테두리 주변을 한 번 쓸어 경계 판정과 채색 보정을 수행할 수 있다. 그 단계에서 스트로크 보정 코드를 완전히 제거할지 다시 결정한다.
